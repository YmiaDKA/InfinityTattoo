# Guesses to replace after the rescan

The Linework capture (`docs/studio/linework-reference/`) came from an empty trial studio: no artists, no clients, payments off. Some pages only showed an empty state, a promo or a gate. Those parts of the studio system are built as reasonable guesses so everything works now. Each one is marked `PLACEHOLDER-RESCAN` in the code (`grep -rn PLACEHOLDER-RESCAN studio/`).

When the owner's filled Linework account is captured, compare each item below with the real screens, change the code to match, and remove the marker.

The optional modules can be switched on and off under Innstillinger → Funksjoner. Flash, Anmeldelser and Produkter for salg are on by default.
